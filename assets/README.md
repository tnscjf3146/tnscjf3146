# assets

README에서 쓰는 이미지·GIF를 넣는 폴더.

## 사용법

```markdown
![설명](assets/파일명.png)
```

크기 조절이 필요하면 HTML 태그를 쓴다. 마크다운 문법으로는 안 된다.

```html
<img src="assets/파일명.gif" width="600">
```

## 주의

- GIF는 **10MB 이하**로 유지할 것. 넘으면 GitHub에서 안 뜨거나 매우 느려진다
- 파일명은 영문·숫자·하이픈으로. 한글이나 공백이 들어가면 경로가 깨질 수 있다
- 이 저장소는 **공개**다. 개인정보가 찍힌 화면은 올리지 말 것
