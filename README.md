## 안녕하세요, 주니어 개발자 황순철입니다.

### 업무에 필요한 도구를 직접 만들다

졸업 후 저는 국비 교육을 운영하는 학원에서 행정 업무를 담당했습니다. 2024년에는 AI의 도움을 받아 HTML과 CSS만으로 **저만의 업무 시스템을 제작해 활용했습니다.** 교강사 4명과 일 평균 교육생 90명 규모의 교육장을 **유일한 행정 직원으로서 관리**했으며, 한국직업능력심사평가원의 심사평가 대응 업무도 외부 인력의 도움 없이 수행했습니다.

### 도구가 바꾸는 일의 방식

나사 하나를 조일 때도 손으로 돌리는지, 수동 드라이버를 쓰는지, 전동 드라이버를 쓰는지에 따라 필요한 시간과 노력이 달라집니다. 업무에 필요한 시스템을 직접 만들고 사용하면서, 소프트웨어 역시 **사람이 가진 시간과 역량을 더 효과적으로 쓰게 해주는 도구**라는 것을 느꼈습니다.

### 좋은 설계는 소통에서 시작된다

좋은 도구를 만들기 위해서는 해결할 문제를 구체적으로 파악하고, 사용 목적에 맞게 구상하고 설계해야 한다고 생각합니다. 그 출발점은 무엇보다 **클라이언트와의 소통**입니다. 어떤 불편을 겪고 있고 무엇이 필요한지 충분히 이해해야, 실제 업무에 도움이 되는 시스템을 만들 수 있기 때문입니다.

충분한 소통과 **근거 있는 판단**을 바탕으로, 사용하는 사람에게 도움이 되는 좋은 도구를 만드는 개발자가 되고 싶습니다. 감사합니다.
